How this page gets here

  1. I edit index.html on my computer.
  2. I run git push to send it to GitHub.
  3. The workflow in .github/workflows/deploy.yml starts on its own.
  4. A minute later, this page shows the change.

What I’m learning

Continuous integration (CI) means every push is checked automatically. Continuous deployment (CD) means a passing check goes live automatically. This small site is my practice project for both.
